# 사장님이 눈으로 확인할 것

작성 2026-09-05. 토큰·결제 기능은 만들었고 API 는 도커에서 전 구간 돌려 봤지만,
**화면 상당수는 사람 눈으로 본 적이 없다.** 아래는 클릭 순서와 기대 결과다.

읽는 법:

- **[지금 바로]** — 아무 설정 없이 확인 가능
- **[키 필요]** — `01-todo.md` 의 해당 항목을 먼저 해야 함
- 기대 결과와 다르면 그 줄을 그대로 복사해서 알려 주시면 됩니다

로컬 주소는 `http://localhost:3000` 기준입니다.

---

## A. 토큰 기본 — 가입하면 20토큰

### A-1. 가입 지급 **[지금 바로]**

새 이메일로 가입 → `/settings/billing`

기대:

- 큰 숫자로 **20 토큰**
- 그 아래 `Gemini 20장 (장당 1)` · `OpenAI 5장 (장당 4)`
- 사용 내역에 `가입 지급 +20 / 잔액 20` **한 줄만**

로그아웃 후 다시 로그인해도 **줄이 늘지 않아야** 한다(두 번 지급되면 버그).

### A-2. 에디터 헤더 잔액 **[지금 바로]**

에디터 오른쪽 위 코인 아이콘 + 숫자.

기대: 잔액 1 이상이면 회색, **0 이면 빨강**. 클릭하면 `/settings/billing` 으로 이동.

이어서 API 를 잠깐 내리고 에디터를 새로고침 →
**배지가 아예 사라지고, 오류 화면 없이 캔버스는 계속 편집 가능**해야 한다.
(잔액을 못 읽었다고 그림 그리던 화면이 오류로 바뀌면 안 된다.)

---

## B. 그림 생성과 차감

### B-1. 키가 없는 지금 상태 **[지금 바로]**

컷 선택 → 장면 설명 입력 → **생성하기**

기대: 잠시 뒤 실패 토스트 `이미지를 만들지 못했습니다.` + 인스펙터에 붉은 상자.
그리고 **`/settings/billing` 사용 내역에 '그림 생성' 줄이 생기지 않고 잔액도 그대로**여야 한다.
(키가 없어 애초에 차감 전에 막히는 것이 정상)

### B-2. 키를 채운 뒤 정상 생성 **[키 필요 → 01-todo 1번]**

헤더 잔액 숫자를 적어 둔다(예: 20) → **생성하기**

기대:

- '생성 중…' 동안 배지는 **20 그대로**
- 완료 토스트 `이미지 생성 완료` 뒤 배지가 **19**
- 사용 내역 맨 위 `그림 생성 (gemini-3.1-flash-image-preview) -1 / 잔액 19`

### B-3. 취소하면 돌아온다 **[키 필요]**

잔액을 적어 둔 뒤 생성 시작 → 'AI 서비스' 절의 **'생성 중…' 옆 취소**

기대:

- 토스트 `이미지 생성을 취소했습니다.`
- **헤더 잔액이 시작 전 숫자와 같다**
- 사용 내역에 `그림 생성 -1` **바로 위에** `환급 +1` — 두 줄이 짝으로

> 워커가 아직 키를 안 받아 간 타이밍이면 **두 줄 다 없는 것도 정상**이다.
> 그때도 잔액은 그대로여야 한다. **한쪽만 남으면 버그다** — 그 화면을 캡처해 주세요.

### B-4. 잔액이 모자랄 때 **[지금 바로 — /admin 필요]**

`/admin` 토큰 조정으로 그 계정 잔액을 **0** 으로 만든 뒤, 에디터에서 컷 선택.

기대:

- 생성하기 버튼에 `· 1토큰` 이 붙어 있고
- 바로 아래 작은 글씨 `토큰이 모자랍니다 (필요 1, 잔액 0). 충전하기`
- '충전하기' 는 `/settings/billing` 으로 이동
- **버튼은 여전히 눌린다** (일부러 안 잠갔다 — 방금 받은 지급이 캐시에 아직 안 보일 수 있어서)
- 눌렀을 때 붉은 상자에 `토큰이 1개 필요한데 잔액이 0개입니다. 충전 후 다시 시도해 주세요.`
- 'AI 서비스' 를 OpenAI 로 바꾸면 같은 자리가 `· 4토큰 / 필요 4` 로 바뀐다

### B-5. 빈 컷 + 잔액 0 — 어느 쪽을 먼저 말하나 **[지금 바로]**

잔액 0 계정에서 **아무것도 안 적은 새 컷** 선택 → 생성하기

기대: 붉은 상자 문구가 **토큰 부족이 아니라**
`본문, 콘티, 참조 이미지 중 하나는 있어야 생성할 수 있습니다.`

> 버튼 아래 '토큰이 모자랍니다' 안내는 그대로 떠 있는 게 정상이다(그건 잔액만 보는 표시).
> 여기서 토큰 부족이 먼저 뜨면, 사용자가 충전하러 갔다가 돌아와서야 컷이 빈 걸 알게 된다.

## C. 충전 (판매)

### C-1. 안내가 비었을 때 **[지금 바로]**

`/settings/billing` → '충전' 절

기대:

- 회색 박스 `지금은 충전을 받고 있지 않습니다. 준비되면 이 화면에서 안내드리겠습니다.`
- 패키지 카드 3장(50토큰 5,000원 / 120토큰 10,000원 / 700토큰 50,000원)은 **보이되**
- **'충전 요청' 버튼은 어느 카드에도 없다**

### C-2. 안내를 채운 뒤 **[설정 필요 → 01-todo 5번]**

`BILLING_NOTICE` 를 **`.env`** 에 넣고 API 재기동(`pnpm prod:restart`) → `/settings/billing` 새로고침

기대:

- 안내 박스가 `자동 결제는 아직 없습니다. …` + 내가 적은 문구로 바뀐다
- 카드마다 **'충전 요청' 버튼**이 생긴다
- 50토큰 카드 버튼 클릭 → 다이얼로그에 **같은 안내가 한 번 더** 보인다
  (누르는 화면에서 계좌가 안 보이면 안 되니까)
- **입금자명이 비면 '충전 요청' 이 안 눌린다**
- '홍길동' 입력 후 클릭 → 토스트 `충전 요청을 접수했습니다. 입금이 확인되면 50토큰이 들어옵니다.`
- 아래 '충전 요청' 절에 `50토큰 · 5,000원` / `홍길동 · (오늘) 접수` 줄이 생긴다

### C-3. 요청 취소 **[C-2 이후]**

충전 요청 줄 오른쪽 **취소**

기대:

- 확인창 제목 `충전 요청을 취소할까요?`
- 본문 `아직 입금하지 않으셨다면 그대로 취소해도 됩니다. 이미 보내셨다면 취소하지 마세요.`
- '요청 취소' → 배지가 **'취소됨'** 으로 바뀌고 '취소' 링크가 사라진다

## D. 운영자 화면 (`/admin`)

### D-1. 입금 확인 → 지급 **[C-2 이후, 관리자 계정 필요]**

`/admin` → 맨 위 '입금 확인 대기'

기대:

- 노란 **'1건'** 배지와 표 한 줄: 굵게 **홍길동**, 그 아래 `가입이메일 · starter`,
  금액 `5,000원`, 지급 토큰 `50`, 접수 날짜
- '입금 확인' 클릭 → 확인창 `(이메일) 에게 50토큰을 지급할까요?` +
  본문 `홍길동 이름으로 5,000원 입금을 확인했을 때만 누르세요.`
- '지급' → 토스트 `토큰을 지급했습니다.`
- 그 줄이 목록에서 사라지고, 아래 '최근 가입' 표의 해당 사용자 토큰 칸이 **50 늘어난다**
- 사용자 탭에서 `/settings/billing` 새로고침 → 주문 배지가 초록 **'지급 완료'**,
  잔액 +50, 사용 내역 맨 위 `충전 +50`

### D-2. 토큰 조정 **[관리자 계정 필요]**

'최근 가입' 표 오른쪽 **토큰 조정**

기대:

- 부제가 `(이메일) · 현재 20토큰`
- 수량 `50` 입력 → 아래에 `50토큰을 지급합니다.`
- **사유를 비우면 '적용' 이 안 눌린다**
- 사유 입력 후 적용 → 토스트 `처리했습니다. 잔액 70토큰.`
- 이어서 `-999` 입력 → `999토큰을 회수합니다.` → 적용 →
  토스트가 **`회수할 수 있는 것보다 많습니다 (요청 999, 잔액 70).`**

> ⚠️ 여기서 `충전 후 다시 시도해 주세요` 가 뜨면 **잘못된 것**입니다(운영자에게 할 말이 아님).
> 최근에 고친 부분이라 특히 봐 주세요.

### D-3. 권한 차단 **[지금 바로]**

일반 계정으로 로그인한 채 `/admin` 을 직접 연다.

기대: `접근할 수 없는 화면입니다 / 운영자 계정으로 로그인해야 볼 수 있습니다.` 만 보이고
통계·표·버튼이 **전혀 없어야** 한다.
`ADMIN_EMAILS` 에 적힌 주소라도 **이메일 인증 전이면 같은 차단 화면**이어야 한다.

## E. 알아 두면 되는 것 (버그 아님)

### E-1. 지급해도 사용자 화면이 저절로 안 바뀐다

운영자가 지급한 뒤 사용자 탭을 건드리지 않고 1분쯤 두면 헤더 숫자가 그대로다.
탭을 클릭해 포커스를 줘도 그대로고, **F5 해야** 새 숫자가 나온다.

지금은 그렇게 동작한다. 불편하면 말씀해 주세요 — 실시간 갱신은 따로 붙여야 합니다.

### E-2. 문구를 정하실 것 두 개

- 충전 지급 내역이 **`충전 starter 충전 +50`** 으로 보인다. 내부 상품 id 가 노출되고
  '충전' 이 중복이다. 한글 상품명으로 바꿀지 판단해 주세요.
- 운영자 지급/회수 내역에 **`(by user_01M1...)`** 운영자 내부 id 가 사용자에게 그대로 보인다.
  가릴지, 이름으로 바꿀지 판단해 주세요.

### E-3. `/admin` 첫 문단이 사실과 다르다

제목 '운영 현황' 아래에 `읽기 전용입니다. 여기서는 아무것도 바꿀 수 없습니다.` 라고 적혀
있는데, 바로 밑에 '입금 확인'·'토큰 조정' 버튼이 있다. 토큰 기능이 붙으면서 문구만 남았다.
고쳐 두라고 하시면 바로 고칩니다.

## F. 여유 있을 때

- **사용 내역 더 보기**: 내역이 9줄 이상일 때 '더 보기' 가 나오고, 한 번 누르면 나머지가
  펼쳐지고 버튼이 사라진다. 31줄째부터는 아예 오지 않는다.
- **BYOK 표시**: `FEATURE_API_KEYS=1` 로 켜고 자기 Gemini 키를 등록하면,
  `/settings/billing` 이 `Gemini 제한 없음 (무료)` 로 바뀌고 **잔액을 0 으로 만들어도**
  에디터에 '토큰이 모자랍니다' 가 뜨지 않아야 한다. (최근에 고친 부분)
