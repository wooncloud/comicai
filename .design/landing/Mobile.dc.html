여덟 장면, 같은 사람

캐릭터 설정을 한 번 적어두고 배경과 장면만 바꿔가며 생성했습니다. 얼굴도, 옷차림도, 그림체도 흔들리지 않습니다.

세 단계면 됩니다

그림 실력 대신 이야기만 준비하세요.

1

캐릭터와 그림체를 등록

이름, 생김새, 옷차림을 한 번 적어두면 프로젝트 전체에서 다시 씁니다.

2

컷에 장면을 쓰기

문장 안에서 @로 등장 인물과 배경을 부르면, AI가 누구를 어디에 그릴지 압니다.

3

이미지 생성

마음에 들 때까지 다시 생성하고, 지난 결과도 남습니다. 완성한 페이지는 PNG·JPG로 내보냅니다.

API 키 등록 안내

ComicAI는 내 API 키를 직접 등록해 사용합니다. Gemini는 Google AI Studio, OpenAI는 Platform에서 발급받은 키를 설정 화면에 등록하면 됩니다. 키는 서버에 안전하게 암호화되어 저장됩니다.
